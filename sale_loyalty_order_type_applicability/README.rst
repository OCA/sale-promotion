This module extends the functionality of sale_loyalty and
sale_order_type to allow you to configure in which sale order types your
loyalty programs will be applied.

As the default behaviour of Odoo applies loyalty programs to all order
types, this module serves to restrict loyalty programs to order types.

Configuration
=============

To configure this module, you need to:

1. Go to Sales / Products / Discount & Loyalty
2. Open or create a Loyalty Program
3. Make it avaliable on Sales
4. Set the Sales Order Types where this Loyalty Program should be
   applied.

Usage
=====

To use this module, you need to:

1. Create a Sales Order with a type that has a restricted loyalty
   program.
2. Click the "Coupon Code" button to use a code to get a reward. The
   coupons of the restricted loyalty programs won't generate any
   rewards, showing a warn message.
3. Select some products that generate any kind of reward. Click the
   "Reward" button to get that reward. The restricted loyalty programs
   won't generate any rewards.
4. Confirm the order to trigger rewards of automatic loyalty programs
   (as loyalty cards). The restricted loyalty programs won't generate
   any rewards.
