To use this module, you need to:

1. Create a Sales Order with a type that has a restricted loyalty program.
2. Click the "Coupon Code" button to use a code to get a reward. The coupons of the restricted loyalty programs won't generate any rewards, showing a warn message.
3. Select some products that generate any kind of reward. Click the "Reward" button to get that reward. The restricted loyalty programs won't generate any rewards. 
4. Confirm the order to trigger rewards of automatic loyalty programs (as loyalty cards). The restricted loyalty programs won't generate any rewards.
