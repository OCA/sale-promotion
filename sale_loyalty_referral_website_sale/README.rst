Bridge between ``sale_loyalty_referral`` and eCommerce: carts created in
a referral session are attributed to the referrer and the referral code
is applied automatically, so the friend sees the discount at checkout.
Anonymous visitors are encouraged to log in so the referral ties to
their account.

Usage
=====

- A visitor who opens a ``?referral=<code>`` link gets a cart attributed
  to the referrer, with the referral code applied automatically — the
  discount shows at checkout.
- Anonymous visitors see a "log in to redeem" notice on the cart page
  until they identify themselves.
