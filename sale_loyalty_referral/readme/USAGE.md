- Staff creates codes per partner on the partner form (Sales & Purchase >
  Referral > "Generate Referral Code"; the code, shareable link and referred
  count show there), in bulk via the partner list Action > Generate Referral
  Code (uses the default referral program).
- Partners can also opt in themselves through the "Invite a Friend"
  block placed on a website page, where they see the copyable link, the
  bare code and the count of visitors who converted.
- The referral program form shows every created code under the "Referral
  Codes" smart button, each linked to its referrer.
- Friends open the link; their eligible order gets the configured reward —
  automatically where an integration applies it, or by typing the code in any
  promo code field. Either way the order records `referred_by_id`.
- Failed applications never block a checkout; they are noted on the order's
  chatter instead.
